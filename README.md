# 📊 Store Annual Report – Vrinda Store

## 📌 Project Overview

This project analyzes annual sales data of Vrinda Store using Microsoft Excel. 
The objective is to understand sales performance, customer behavior, order trends, 
and identify key business insights through data analysis and visualization.

## 🛠️ Tools & Technologies

- Microsoft Excel
- Data Cleaning
- Data Analysis
- Pivot Tables
- Pivot Charts
- Excel Formulas
- Data Visualization
- Dashboard

## 📂 Project Files

- `Vrinda Store Data Analysis.xlsx` – Complete Excel analysis and dashboard
- `Dashboard.png` – Project dashboard preview

## 📈 Key Analysis

- Monthly sales and order trends
- Sales comparison between men and women
- Order status analysis
- Top-performing states
- Age-group wise sales analysis
- Sales channels analysis
- Category-wise performance
- Customer purchasing patterns

## 🎯 Project Objective

The main objective of this project is to analyze store sales data and generate 
meaningful insights that can help understand customer behavior, sales trends, 
and overall business performance.

## 📊 Dashboard

The Excel dashboard provides an interactive view of important sales KPIs 
and business insights.
