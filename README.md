# Store Annual Report

## 📊 Project Overview
This project analyzes store sales data using Microsoft Excel to identify sales trends, customer behavior, and business performance.

## 🛠️ Tools & Technologies
- Microsoft Excel
- Pivot Tables
- Excel Charts
- Data Cleaning
- Data Analysis

## 📈 Key Analysis
- Sales and order analysis
- Monthly sales trends
- Category-wise performance
- Customer and product analysis
- Interactive dashboard

## 🎯 Objective
To analyze store sales data and generate meaningful business insights through Excel-based reporting and visualization.
